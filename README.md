# HTML Personal Profile Page

## Explanation

This project demonstrates how to create a simple personal profile page using HTML. It displays personal information, education, skills, hobbies, and contact details.

## Problem Statement

Create a personal profile webpage using basic HTML elements to display information about a person.

## Features

* Profile heading
* Personal information
* Education details
* Skills list
* Hobbies list
* Contact information

## How It Works

Headings are used to organize the profile sections.

Paragraphs display personal information.

Unordered lists are used to display skills and hobbies.

The `<a>` element is used to provide an email contact link.

## Technologies Used

* HTML5

## Program Flow

1. Open the profile webpage.
2. Display the profile heading.
3. Display personal information.
4. Display education details.
5. Display skills.
6. Display hobbies.
7. Display contact information.

## Sample Input

Name: Harini
Course: B.Tech
Skills: C, Java, HTML
Hobbies: Reading, Coding

## Sample Output

A personal profile webpage containing the person's information, education, skills, hobbies, and contact details.

## Key Learning

* HTML headings
* Paragraphs
* Unordered lists
* Links
* Organizing webpage content
